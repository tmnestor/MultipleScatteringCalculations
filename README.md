# MultipleScatteringCalculations

Elastic multiple scattering from cubic heterogeneities by the T-matrix method. The medium is divided
into cubes; each cube scatters through a single-site T-matrix `T₀`, the cubes are coupled by the
inter-site Green's tensor `G₀`, and the Foldy–Lax system `T = T₀ (I − G₀ T₀)⁻¹` carries the multiple
scattering. The work originates in T. M. Nestor's PhD thesis (Australian National University, 1996).

The principal product is the mathematics, written up in LaTeX. The Python and Wolfram Language code
exist to validate it: every result in the documents is checked by two independent implementations,
one symbolic and one numerical.

## The continuum-limit paper

*The Continuum Limit of a Space-Filling Layer of Cubes: A Tiling Identity, an Exact Lattice Kernel,
and the Closed-Form Error of the Discrete Layer* — T. M. Nestor.

## Repository layout

| Folder | Contents |
|---|---|
| `cubic_scattering/` | The Python package: single-site T-matrices, inter-site propagators, Foldy–Lax solvers, reference solutions. Tests in `cubic_scattering/tests/`. |
| `Mathematica/` | Symbolic derivations and high-precision references (`.wl` scripts and notebooks). `TakeuchiSaito.wl` is a self-contained library for the radial equations of a spherically stratified elastic body; run `TSSelfTest[]` after loading it. |
| `scripts/` | Measurement scripts. `gate_*.py` are pass/fail checks, `crosscheck_*.py` compare against the notebooks, `pilot_*.py` are exploratory measurements. |
| `LatexPDFs/`, `docs/`, `paper/` | LaTeX documents and their PDFs. |
| `FFTProp.py/` | A Python port of the thesis Fortran, including the directional sweeps. |
| `PhD_fortran_code/` | The thesis Fortran and related reference code. |

Documents can lag the code. Where a document and a validated script disagree, trust the script.

## Setup

```bash
conda env create -f envs/seismic.yml
conda activate seismic
```

## Running

```bash
# Package tests (the full suite is slow; run a single file first)
conda run -n seismic python -m pytest cubic_scattering/tests/ -v

# A gate or cross-check
conda run -n seismic python scripts/<name>.py

# A Wolfram Language script
wolframscript -file Mathematica/<name>.wl

# LaTeX: the article needs lualatex (fontspec); run twice, with bibtex where a .bib is used
cd LatexPDFs/ContinuumLimit && lualatex ContinuumLimit.tex
```

## Conventions

- Coordinates: z is axis 0 (down), x is axis 1, y is axis 2; right-handed.
- Time dependence `e^{−iωt}`; scattered waves are outgoing `e^{+ikr}`.
